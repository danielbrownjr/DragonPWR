# Panda PWR V2 hardware images

This directory is reserved for verified, shareable Panda PWR V2 (ESP32-C3) hardware photographs and annotated reference images.

The Rev 1 (ESP32-C2) teardown photos live in [`../v1/`](../v1/). Do **not** reuse them as evidence for V2 pinout, electrical connections, switching behavior, or component placement.

Do not publish private factory firmware, NVS, device identifiers, or confidential reverse-engineering materials here. Hardware qualification and mains-safety requirements remain unchanged.
