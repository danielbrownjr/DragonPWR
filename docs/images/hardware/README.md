# Hardware image library

- [`v1/`](v1/) contains photographs of the destructively opened original Panda PWR Rev 1 / ESP32-C2 unit, referenced by [`docs/HARDWARE_ANALYSIS.md`](../../HARDWARE_ANALYSIS.md).
