# DragonPWR 0.0.1rc1

First DragonPWR release candidate for the BIGTREETECH Panda PWR.

This release intentionally freezes the **Phase 1** product baseline before
printer-aware policy and live HLW8112 metering are added.

## Included

- ESP8684-MINI-1-H4 / ESP32-C2 target with the confirmed 26 MHz crystal setting
- safe relay initialization, with mains off as the default restore policy
- mains relay and USB1 control
- physical Bind button on GPIO10
- GPIO6 observed/logged but deliberately unable to switch mains
- dragon-core Wi-Fi provisioning, captive portal, mDNS and browser OTA
- DragonPWR product API v2
- stock-compatible `/set` and `/update_ele_data` routes
- control-token authorization and CSRF protection for the stock mutation route
- event log, device/boot identity and OTA boot diagnostics
- restart, factory-reset and inactive-slot maintenance routes
- reboot/OTA/factory-reset guard while the mains outlet is on
- temporary `/power` browser control page
- Phase 1 RAM tuning and heap diagnostics
- complete hardware-analysis, bench, recovery and metering-reverse-engineering docs

## Not included yet

- live HLW8112 voltage/current/power/energy/frequency reporting
- printer source integration
- print-aware power-off interlock or cooldown policy
- countdown/idle shutdown
- MQTT/Home Assistant discovery
- dedicated DragonPWR surface in the shared dragon-core UI

The stock HLW8112 metering path is already recovered in detail and is sufficient
to implement `dp_meter`; that implementation is deliberately held for the next
development slice rather than being slipped into this release candidate.

## Flashing

### Existing DragonPWR installation

With the **mains outlet switched off**, upload:

`DragonPWR-0.0.1rc1-ota.bin`

through DragonPWR's browser OTA surface.

### First DragonPWR install or bootloader refresh

Back up the complete stock flash first, disconnect the IEC mains input, power
from USB-C only, then flash the merged image at address `0x0`:

```text
python -m esptool --chip esp32c2 -p COM6 -b 460800 write_flash 0x0 DragonPWR-0.0.1rc1-full.bin
```

A full serial flash is also the way to ensure the device has the current
rollback-enabled DragonPWR bootloader. An app-only OTA cannot replace an older
bootloader.

## Verification after flash

- firmware version reports `0.0.1rc1`
- mains boots in the configured restore state, default off
- `GET /api/v2/info` reports product `dragonpwr`
- `GET /api/v2/state` reports real mains/USB state and sane heap values
- `meter` and `printer` remain `null` in the v2 state until those features land
- browser OTA/restart/factory-reset/boot-inactive operations refuse while mains is on

## Safety / RC status

This is a **prerelease**. The Phase 1 switching and management baseline has been
bench-tested on real Panda PWR hardware, but it does not yet know printer state.
Do not treat it as a print-aware interlock.

SHA-256 hashes for the release binaries are included in `SHA256SUMS.txt`.
